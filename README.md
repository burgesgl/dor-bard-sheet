# Dor — Bard Sheet

Interactive D&D 5e (2014) character sheet for Aedian D. Olian "Dor", half-elf bard, Silverquill Student.

Open `index.html` in a browser, or turn on GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).

- Tap any modifier, skill, save, or attack to roll. Adv/Dis toggle resets after each roll.
- Tracks HP, temp HP, spell slots, Bardic Inspiration, the free Dissonant Whisper, hit dice, and death saves.
- Short and long rest buttons reset the right resources.
- "Edit sheet" unlocks scores, skill proficiencies, text, gear, and spells.
- Progress saves in your browser automatically for the whole campaign.
- "Save to file" downloads a backup to your computer; "Load file" restores it on any device.

## On iPad

Open the link in Safari, tap Share → Add to Home Screen. It opens full screen like an app.
Heads-up: the home-screen app keeps its own saved data, separate from Safari. Pick one and stick with it, or use Save to file / Load file to move between them.
